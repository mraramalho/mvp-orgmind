# Decisões em aberto

Não há decisões em aberto registradas neste momento.

## Processo de decisão

Quando surgir uma decisão ainda não coberta pelas especificações:

1. registre a alternativa escolhida e a justificativa;
2. crie um ADR se a decisão afetar arquitetura, segurança ou substituição futura;
3. atualize este arquivo, removendo o item resolvido;
4. atualize os comandos e exemplos operacionais afetados.
